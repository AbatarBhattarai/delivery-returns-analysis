# Delivery and Returns Analysis

By Abatar Bhattarai — CIS student at East Texas A&M, graduating May 2027

I did this project to practice data analysis with Python, SQL, and Excel.

I cleaned a messy orders file in Python (pandas) — removed duplicates and filled missing values. Then I used SQL to look at return rates by category, shipping method, and region, and made a summary in Excel.

## What I found
- 900 orders, 11.6% returned
- Clothing returned most: 16.7%
- Express shipping: 7.7% returns, Standard: 13.6%
- Returned orders took 4.1 days on average, kept orders took 3.6 days

## Files
- `orders_raw.csv` — the messy data I started with
- `analysis.py` — my Python cleaning script
